Mini Edition | https://github.com/stzzyy/FlareLinux-x86_64/tree/mini

## How to build
There are 2 main ways to build FlareLinux

### Using FlareBuild
Find the latest release in https://github.com/stzzyy/FlareLinux-x86_64/releases and download FlareBuild.exe, (also download this project and make what ever changes you want). Run FlareBuild and follow the instructions in the program. Once finished the program should have outputted an .iso file that you can run on emulator or real hardware.

In FlareBuild you can also upload your own compiled Linux kernel however this may cause problems if you have a bad config.


### Using FlareLinux Installation Media
Go to https://github.com/stzzyy/FlareLinux-InstallMedia/releases and download the .iso that matches with your target cpu archetecture then execute in an emulator or write to a drive with Rufus and then execute on real hardware
